# ☕ McFluff Coffee Sales Counter

A simple, interactive coffee sales tracker built with HTML, CSS, and JavaScript.  
This was one of my first JavaScript projects, where I practised linking logic to real-time updates on a webpage.

---

## 💡 Overview
I built this project early in my coding journey to understand how to connect JavaScript functionality to HTML elements.  
It simulates a sales counter that tracks the number of coffees sold — a playful concept inspired by my “McFluff” brand theme.  

Through this project, I learned how to use **functions, DOM manipulation, and event handling** to create an interactive user interface.

---

## 🧠 What I Learned
- How to use **`document.getElementById()`** to link HTML elements to JavaScript variables.  
- How to **increment and update text content dynamically** using JavaScript.  
- The difference between **`.innerText`** and **`.textContent`**, and when to use each.  
- How to **use `+=`** to append new information to existing text on a page.  
- The importance of **placing `<script>` tags** at the end of the HTML body to ensure elements load properly before scripts run.  
- How to organise small scripts cleanly for readability and reusability.  
- How to start structuring projects in a single folder with linked HTML, CSS, and JS files.

---

## 🧩 Features
- 🧮 Tracks the number of items sold in real time.  
- 👆 Simple “increment” and “save” buttons to record totals.  
- 🪄 Updates displayed values automatically on button click.  
- 💾 Resets the counter after each sale log.  
- 🧼 Clean, minimalist layout with custom colour and font styling.  

---

## 🚀 Future Improvements
- Store daily totals using **local storage** so data persists on refresh.  
- Add a date or session tracker for sales history.  
- Improve mobile responsiveness and layout spacing.  
- Refactor repetitive code into smaller, reusable functions.
